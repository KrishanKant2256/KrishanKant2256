### 🎙️ Sentry
*A tiny device listening for one word.*

An edge voice-activation prototype where an ESP32 acts as the bridge between audio capture, wake-word detection and command processing.

The interesting part? The goal isn't to send everything to a server. The device should be able to decide:

```text
AUDIO
  │
  ▼
┌─────────┐
│  ESP32  │
└────┬────┘
     │ Wake word?
  ┌──┴──┐
 NO    YES
  │     │
  ▼     ▼
Ignore Send clip ──► Processing
```

`ESP32` • `TensorFlow Lite` • `Python` • `Audio Processing`
